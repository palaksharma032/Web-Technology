## 📖 About

This repo is built for two purposes:

- **Learn**: understand every concept from the ground up, with clear explanations and examples.
- **Revise**: come back before interviews and quickly refresh everything, without opening any other resource.

Every topic has four parts:

1. **Notes**: a detailed explanation: what it is, why it matters, syntax, examples, common mistakes.
2. **Code**: small, runnable examples you can open and experiment with.
3. **Exercises**: practice tasks to apply what you just learned.
4. **Interview questions**: frequently asked questions with concise answers.

---

## 🔁 Learning Path

Each topic follows the same loop:

| Step | What to do | File |
|------|-----------|------|
| 1. Learn | Read the notes and understand the concept | `notes.md` |
| 2. See it | Run the example and change it | `index.html` / `.js` / `.jsx` |
| 3. Practice | Solve the exercises without looking at the notes | `exercises.md` |
| 4. Revise | Answer the interview questions out loud | `interview-questions.md` |

Study order: **HTML → CSS → JavaScript → React**. Each section builds on the one before it.

## 🚀 How to Use This Repo

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/web-dev-learn-and-revise.git
   cd web-dev-learn-and-revise
   ```
2. **Learning for the first time?** Go in order, and follow the 4-step loop for every topic.
3. **Revising before an interview?** Skim `notes.md`, then go straight to `interview-questions.md`. Revisit `exercises.md` for any topic that feels weak.
4. Open HTML, CSS and JS examples directly in the browser. For React topics, run `npm install` and `npm run dev` inside the topic folder.

---

## 📝 Notes Format

Every `notes.md` follows the same order, so both learning and revision stay fast:

1. **Definition**: what it is, in one or two lines, in simple words
2. **Why it matters**: where and why it is used
3. **Syntax and examples**: built up from simple to advanced
4. **Common mistakes and gotchas**
5. **Quick summary**: key points for fast revision
6. **Interview angle**: how it is usually asked
